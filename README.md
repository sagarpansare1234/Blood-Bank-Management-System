# Blood Bank Management System (BBMS)

## Overview
This is a **Windows Desktop Application** developed in **C# with WinForms** for managing a blood bank.  
It handles donor management, blood inventory, and transactions in an organized manner.

## Features
- Add, view, delete, and search blood donors
- Dashboard showing key statistics
- CRUD operations implemented with database connectivity
- Modular design using OOP principles
- User-friendly interface using WinForms

## Project Structure
- `AddNewDonor.cs` – Form to add new donors  
- `DeleteDonor.cs` – Form to delete donor entries  
- `Dashboard.cs` – Main dashboard UI  
- `Form1.cs` – Main entry form  
- `function.cs` – Utility functions for common tasks  
- `images/` – Project images used in UI  
- `bin/` & `obj/` – Build folders  
- `.resx` files – Resource files for UI elements  

## Setup
> **Note:** The code is complete; currently it may require local setup (Visual Studio + SQL Server) to run.

1. Clone the repository
2. Open the solution (`bbms.sln`) in **Visual Studio**
3. Restore NuGet packages if needed
4. Connect to your local SQL Server database
5. Run the project
